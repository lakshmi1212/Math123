# Math Operations

This repository contains Python functions for basic math operations (addition and subtraction) and corresponding test cases.

## Files

- `src/math_operations.py`: Contains the `add` and `subtract` functions.
- `tests/test_add.py`: Test cases for the `add` function.
- `tests/test_subtract.py`: Test cases for the `subtract` function.
- `math.json`: Metadata for CI workflow.
- `requirements.txt`: Dependency file.

## Usage

1. Clone the repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run tests using `pytest tests/`.

## CI Workflow

This repository is set up with a CI workflow to automatically run tests on each commit.
